PROJECT OVERVIEW

Lotus Lingo is a conceptual mobile language-learning application created as an academic UI/UX design project. The app was designed to explore how visual design, structured lessons, and interactive experiences can support users as they learn a new language. All included imagery and language-learning content were used solely for educational purposes as part of the course project.

The goal was to design a complete language-learning ecosystem that guides users from account creation through daily practice, lesson progression, and community engagement. The project included more than 100 designed screens covering onboarding, user profiles, settings, lesson modules, progress tracking, games, rewards, premium features, and additional app functionality.

CREATIVE DIRECTION

The visual direction combines playful illustration, bright colors, and approachable interface patterns to create an encouraging learning environment. The design system was developed around accessibility and engagement, using consistent navigation, visual feedback, and interactive components to help users feel motivated throughout their language-learning journey.

The app architecture was organized around five primary learning modules focused on reading, writing, speaking, and comprehension. Each lesson system was designed with structured practice activities, progress indicators, review sections, and personalized learning tools. Additional features including calendars, user statistics, friends, community interaction, achievements, music, account management, and premium options were created to demonstrate how a complete mobile product experience functions beyond the core lesson content.

The featured screens demonstrate English-to-Japanese learning exercises, including Katakana lessons that introduce pronunciation, writing practice, and character recognition. The final prototype explores how thoughtful UI/UX design can transform educational content into an engaging and intuitive mobile experience.

PROCESS

The process began with researching the challenges learners face when using language learning applications. While preparing for a trip to Japan, I explored several existing language apps and identified opportunities to improve engagement, personalization, and long-term retention. Many applications focused heavily on repetition and vocabulary practice, but I found opportunities to create a more immersive experience by incorporating elements of gaming, music, and community-based learning.

Research revealed that learners benefit from multiple methods of engagement and different approaches to processing information. For Japanese language learners specifically, the combination of formal and informal structures, along with multiple writing systems, can create additional challenges. These findings influenced the development of Lotus Lingo’s structure, allowing users to customize their learning experience by focusing on conversational skills, written language, or cultural exploration based on their individual goals.

After identifying key user needs, I developed a high-fidelity Figma prototype containing over 100 pages of lessons, games, community features, and music-based learning experiences. The interface was designed around clear progression, daily engagement, and flexible learning paths. Features such as rewards, community spaces, and cultural content were incorporated to encourage consistent practice while creating a more engaging and personalized language learning experience.

Due to project constraints, the original concept for a larger RPG-style learning game was not fully developed, but the framework was designed to support future expansion. The final prototype demonstrates how research-driven decisions can transform language learning from a repetitive task into a more interactive and motivating experience.
